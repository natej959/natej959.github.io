# Dune Warden: canyon time trial

Single-file low-poly sci-fi rally game. Open `dune-warden.html` by double-clicking it; it works offline
(three.js r160 is inlined, no external requests, no server).

Controls: W/A/S/D or arrows drive, Space drift, Shift boost, R respawn (hold to restart), C camera, M mute, P pause.

Source lives in `src/`. Rebuild the single file with `node src/build.mjs`.
Handling constants are in the `CFG` block at the top of `src/game.js`.
